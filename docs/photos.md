# Photo library

Web-size copies (longest edge 2400px, metadata stripped) of Andrew's studio portraits live in `assets/photos/`, which is git-ignored. Originals are in `~/Pictures/touched-up-pictures`. Photos chosen for the site are copied into `src/lib/images/` and are the only ones committed.

Photographer: Doug Silton (<https://dougsilton.com/>), credited in the site footer.

Every photo is a solo studio shot of Andrew. Most poses exist in a colour and a black-and-white version; the site uses the black-and-white versions so vermilion stays the only colour on the page.
